# Campus Hub 🏫

A full-stack campus management web application with AI chatbot.

## Features
- Student issue reporting and tracking
- Admin dashboard with statistics
- AI powered chatbot using Groq LLaMA 3.3
- JWT authentication
- Real time announcements

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- AI: Groq API (LLaMA 3.3 70B)
- Hosting: Railway + Netlify
